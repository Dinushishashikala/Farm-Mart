# 🌾 Farm Mart – Online Agriculture Marketplace

## 📌 Project Overview
**Farm Mart** is a web and mobile-based agriculture marketplace developed as a **Second Year Skill Development Group Project**.  
The system connects **farmers**, **sellers**, and **customers** through a digital platform, enabling farmers and sellers to list agricultural products and manage sales efficiently.

---

## 🎯 Project Objectives
- Provide a digital marketplace for agricultural products  
- Support farmers and sellers in managing products and orders  
- Improve accessibility and efficiency in agricultural trading  
- Apply real-world development skills using modern technologies  

---
